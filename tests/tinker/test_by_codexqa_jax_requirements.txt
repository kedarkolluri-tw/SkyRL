# Isolated CPU environment for the JAX backend tests.
#
# Separate from the torch requirements because the backend extras are
# mutually exclusive -- uv refuses to resolve jax alongside fsdp/megatron --
# so the two suites need two interpreters.
#
# Pinned, not ranged. The original `jax>=0.8,<1.0` also admits 0.11.2, which
# breaks flax at import:
#     module 'jax.experimental.hijax' has no attribute 'HiPrimitive'
#
# The block below omegaconf exists so test_loss_fns can import
# skyrl.train.config.config and assert the JAX defaults match CISPOConfig.
# None of it is a BACKEND dependency -- omegaconf/skyrl-gym/loguru come from
# the skyrl-train extra, which is orthogonal to jax/fsdp/megatron. Leaving
# them out skipped that assertion silently.
#
# They are listed individually rather than pulled in via `--extra skyrl-train`
# because that extra does not resolve on macOS (linux-only deps); on Linux,
# prefer `uv sync --extra tinker --extra jax --extra skyrl-train`.
#
